# 💫 About Me

Hi, I'm **Hassan Younas** 👋

**Data Scientist & ML Engineer** — I build machine learning systems end-to-end: from research and model training to production APIs and dashboards. Based in the UK 🇬🇧

I don't stop at notebooks. Every serious project I ship comes with a real backend, a real frontend, and a Dockerfile.

## 🚀 What I've Built

**[QuantForge-NVDA](https://github.com/Hassan-Younas18/QuantForge-NVDA)** — Deep-learning stock forecasting pipeline<br>
Benchmarked 5 architectures (LSTM, GRU, BiLSTM, CNN-LSTM, Transformer) with MC-Dropout uncertainty intervals, served through a FastAPI backend and React + TypeScript dashboard. Docker-ready.

**[MedBot](https://github.com/Hassan-Younas18/MedBot)** — RAG chatbot for medical documents<br>
Upload any medical PDF and ask grounded questions. Sentence-Transformers embeddings + FAISS semantic retrieval, with answers grounded in the source document — built to reduce LLM hallucination in a high-stakes domain.

**[NewsHarvest](https://github.com/Hassan-Younas18/NewsHarvest)** — Production-grade news scraper<br>
Multi-source pipeline with proxy rotation, retry logic, and crash-safe CSV storage. Designed to survive real-world blocking, not just parse one page.
